# Contributing

## Setup

- Node 22 or newer.
- `npm ci`
- `npm test`

### What skips mean

On machines that are not the pinned custody toolchain (Node v25.9.0 on darwin/arm64), or
that lack a Playwright Chromium install, or that are missing a sample pack, individual
tests skip with a message that starts with `skipped:`:

- pinned render/hash tests: run on the pinned toolchain, or set `HOUSE_BAND_REQUIRE_PINNED=1`
  to force them (they will fail off-pin);
- browser UI tests: install Chromium with `npx playwright install chromium`;
- pack-backed tests: install or build the named pack (see `docs/BRING-YOUR-OWN-SAMPLES.md`
  once that guide lands);
- private-fixture tests: those fixtures are not in the public tree and stay skipped there.

`npm test` should exit 0 with skips explained. `npm run test:pinned` is for the pinned Mac.

## Composing laws

Before proposing score or composer changes, read [docs/COMPOSING-LAWS.md](./docs/COMPOSING-LAWS.md).
Those laws bind composed scores; tests and audit tools enforce the measurable ones.

## Adding a kit

- **Synth kit:** copy an existing synth kit under `src/presets/kits/*.mjs` (for example
  `tr808.mjs`), give it a new `id` and `title`, register it in `src/presets/kits/index.mjs`,
  and add coverage.
- **Sampled kit:** do not commit commercial audio. Build a canonical pack with
  `node bin/house-band.mjs samples build ...` and keep the
  pack outside the repo (or ship only first-party / CC-licensed material as this tree does).

## No commercial audio in PRs

Do not add files from Samples From Mars, BBC Symphony Orchestra, LABS, or any other
commercial library to the repo, fixtures, or site. Test audio is generated by code or
uses the licensed packs already in tree. See [NOTICE.md](./NOTICE.md).
