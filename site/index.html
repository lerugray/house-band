    Bring your own samples

    Point a folder of WAV files at House Band, check the role report, then render. Blue marks your material; grey roles fall back to a synth kit.

    1. house-band samples scan ~/Samples/my-drums
    2. Check the report, edit the mapping if needed
    3. house-band render my-song.json --kit-map tr707=user:my-drums -o my-song.wav

    How it works

    A score is authored data. The renderer is deterministic within a pinned toolchain and writes a WAV plus a custody manifest. 

    {
  "tempo": 96,
  "seed": 42,
  "kit": "tr707",
  "tracks": [
    { "name": "kick", "steps": [1, 0, 0, 0, 1, 0, 0, 0] },
    { "name": "snare", "steps": [0, 0, 1, 0, 0, 0, 1, 0] }
  ]
}

    same score, same seed, same toolchain, same bytes

    Get started

    Node 22+. Clone, install, render a demo score.

    git clone https://github.com/lerugray/house-band.git
cd house-band
npm ci
node bin/house-band.mjs render examples/demo-spec.json -o demo.wav

    Open the GitHub repo for the README sections on render, samples, and co-write.
